Quick key

Minimum = optional or required.
Maximum = one or many.

For educators

This three-round activity helps learners translate natural-language business rules into minimum and maximum cardinality using Crow’s Foot notation. It progresses from unary relationships to binary relationships and concludes with a bridge entity representing a three-way business fact.

  • Runs as one self-contained HTML file in a modern browser.
  • Works for individual practice, pairs, small groups, or classroom projection.
  • Uses immediate explanatory feedback rather than scoring.
  • Stores no responses and uses no external scripts or services.
